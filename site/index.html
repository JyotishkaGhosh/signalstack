How this data is made
A daily ELT pipeline, scheduled with GitHub Actions

3 hiring APIsGreenhouse, Lever, Ashby · daily 06:00 IST
02 · LOAD
Raw → DuckDBDate-partitioned JSON, normalized to one schema, deduplicated
03 · TRANSFORM
SQL modelsraw_jobs → jobs_clean → company_signals → company_scores
04 · EXPORT
data.jsonLatest scores, roles and daily history
05 · SERVE
This dashboardStatic site, rebuilt on every run
